# AGENTS.md

## General development preferences

- Act as a senior engineer.
- Inspect existing code and project conventions before editing.
- Prefer minimal, targeted changes rather than unnecessary rewrites.
- Preserve existing functionality unless the task explicitly changes it.
- Keep code production-ready, responsive, accessible, and maintainable.
- Run relevant lint, type-check, test, or build commands when available.
- Explain important assumptions and any verification that could not be completed.

## Skill usage

Use the most specific available skill for the task:

- `$shopify-developer` for Shopify Liquid, themes, sections, carts, products, collections, and Theme Editor work.
- `$nextjs-developer` for Next.js and React App Router work.
- `$typescript-developer` for TypeScript-focused implementation or type debugging.
- `$sanity-developer` for Sanity schemas, GROQ, Portable Text, Studio, and Sanity/Next.js integration.
- `$prisma-developer` for Prisma schemas, migrations, database queries, and relations.
- `$ai-engineer` for LLM/API integrations, RAG, tools, evals, and AI application architecture.
- `$senior-web-developer` for general web engineering tasks or work spanning multiple areas.

When multiple skills are relevant, combine them rather than forcing the task into only one specialty.
